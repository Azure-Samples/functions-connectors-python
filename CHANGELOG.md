# Changelog

Notable changes to this project are documented in this file.

## Unreleased

### Added

- Microsoft Learn sample metadata for the connector polling and webhook sample READMEs.
- Contributing guide, issue forms, and pull request template.
- GitHub Actions CI that compiles and lints the Python samples and audits dependencies with `pip-audit`, plus a dependency review workflow. CodeQL runs through GitHub default setup. CI uses no secrets.
- Weekly Dependabot updates for Python dependencies; major and minor updates are ignored.
